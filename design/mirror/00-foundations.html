stroke-strong is an accessibility fix, not a style choice. The previous revision drew input and search borders in #D6DEE8 — about 1.3:1 against white, which fails WCAG 2.1 SC 1.4.11 (non-text contrast, 3:1) for interactive controls. Decorative hairlines can stay light because they carry no state; anything a user can focus or type into takes stroke-strong.

ink-3 at 4.9:1 is the floor. Nothing lighter carries text, which rules out the “subtle timestamp” grey every dashboard reaches for.

Motion

Things enter decelerating and leave accelerating.

--dur-fast150ms — hover, press
--dur-normal200ms — expand, reveal
--dur-gentle250ms — panel, drawer
--ease-entercubic-bezier(0,0,0,1) decelerate
--ease-exitcubic-bezier(1,0,1,1) accelerate

Never transition-all — name the properties. A blanket transition animated background-color through a theme switch during this project and produced a mid-transition value that disagreed with the DOM for long enough to send a bug hunt in the wrong direction.

Under prefers-reduced-motion every duration collapses to 1ms and nothing translates.
